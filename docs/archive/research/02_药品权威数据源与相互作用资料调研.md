# 药品权威数据源与相互作用资料调研

核验日期：2026-09-19。地区优先级按中国大陆规划；国际数据只作为补充，不能把美国标签直接当成中国具体厂家/规格的说明书。

## 1. 证据等级与产品原则

本项目采用任务书定义的 A/B/C 三级证据：监管机构与具体药品正式说明书为 A 级；有版本、方法和责任主体的指南、系统综述和专业药物库为 B 级；医院/学会患者教育为 C 级。搜索摘要、普通网页、电商、论坛、未经确认 OCR 和模型记忆不能独立形成权威结论。

来源记录必须保存：来源类型、机构、原始 URL/记录号、药品通用名/商品名、批准文号或 NDC/RxCUI 等标识、厂家、剂型、规格、地区、版本/发布日期、访问日期、原文片段、证据等级和适用限制。

## 3. 国际补充来源

### 3.1 FDA/OpenFDA

- [openFDA Drug API](https://open.fda.gov/apis/drug/) 提供 label、NDC、recall、Drugs@FDA、shortage 等 API。
- [Drug label endpoint](https://open.fda.gov/apis/drug/label/how-to-use-the-endpoint/) 的结构化标签可提供 `drug_interactions`、警告、禁忌等章节，但数据并非适合所有临床/生产用途，必须保留 FDA 免责声明和地区限制。
- [认证与限额](https://open.fda.gov/apis/authentication/)：公开访问有速率/日限额，API key 可提高上限；正式产品不能把公开限额当作 SLA。

用途：作为美国标签的 B/A 级补充，要求记录 `set_id`/版本、国家和标签章节；不替代中国说明书。

### 3.2 DailyMed/SPL

[DailyMed Web Services](https://dailymed.nlm.nih.gov/dailymed/app-support-web-services.cfm) 提供 v2 REST、JSON/XML、SPL 历史、媒体和 NDC/RxCUI/UNII 关联。它的核心是 FDA 当前使用的标签，适合按 NDC/SPL 追溯版本；覆盖和适用地区是美国，许可和再分发仍需逐项确认。

### 3.3 RxNorm

[RxNorm](https://www.nlm.nih.gov/research/umls/rxnorm/index.html) 和 [RxNav APIs](https://lhncbc-portal.lhcaws-prod-pub.nlm.nih.gov/RxNav/APIs/index.html) 提供规范化临床药品名称、RxCUI 与词汇关联。适合作为成分/同义词标准化桥接，但不是中国商品/批准文号库；需遵守 NLM 归属与使用条款。

### 3.4 DrugBank 与 DDInter

- [DrugBank API](https://docs.drugbank.com/v1/) 的数据库/API 是受许可控制的专业资源。[Terms](https://trust.drugbank.com/drugbank-trust-center/terms-of-use) 对商业使用、衍生数据库和安全关键用途有约束；未取得许可前不能作为本项目内置核心数据。
- [DDInter 数据插件仓库](https://github.com/mnarayan1/DDInter) 说明下载数据采用 CC BY-NC-SA 4.0，且仓库是 Biothings plugin，不是一个可无条件嵌入商业 App 的公共 API。可作研究与离线规则原型的候选，但要保留署名、非商业/相同方式共享义务，先确认原始 DDInter 条款和数据版本。
- [DDInter 站点](https://ddinter.scbdd.com/) 提供公开查询/研究介绍；其覆盖、更新、抓取和再分发授权未在本次确认，因此不作为线上自动调用依赖。

结论：本项目不会把 DrugBank、DDInter 或模型记忆包装成“完整权威相互作用库”。若没有可合法使用的全面数据，产品必须显示“已检查的规则范围”和“未覆盖/未确认”，而不是显示“无相互作用”。

## 4. 相互作用检测分层

1. **确定性本地检查**：同一成分重复、相同药物重复、剂型/规格缺失、过敏成分匹配、用户已标记的疾病禁忌和说明书明确警告。
2. **版本化结构化规则**：每条规则含药物标识、条件、风险级别、依据、适用地区、版本和复核日期；规则先于 AI 运行。
3. **官方标签章节**：按具体产品说明书的禁忌、相互作用、特殊人群、用法用量章节检索；OCR 文本必须用户确认。
4. **联网补充**：只通过官方 DeepSeek Harness 的原生 Web Search/Web Fetch 发现并取得候选原文，再按机构、版本、地区和药品匹配筛选；搜索到不等于权威。
5. **AI 解释**：DeepSeek 只能解释已提供的规则和资料，不能凭自身知识决定“能否同服”。

风险等级建议：紧急/高风险提示立即咨询医生或药师；中风险提示核对说明书与专业人士；低风险仅做记录；未知/冲突单独显示，不能降级成“安全”。

## 5. 无法解决的缺口

- 中国大陆药品的稳定、公开、可合法批量再分发 API 未确认。
- 商品名、地方医院制剂、复方/中成药和厂家版本之间的标准化仍需用户确认。
- 没有取得商业许可时，不能声称拥有全面 DDI 覆盖。
- 实时资料会遇到验证码、登录、网页变更、区域限制、标签版本冲突；系统要可离线工作并保留“未检查”。
