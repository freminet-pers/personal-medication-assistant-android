# 历史档案索引 / Archive index

本目录保存项目制作过程中的调研、计划、交付和验收材料。它们对追溯决策有价值，但不是当前产品说明、医疗建议或已发布功能承诺。

## 归档规则

- 归档只改变路径和导航，不删除内容；本次按 GitHub 上原文件路径执行可追溯的 git-mv 式迁移。
- 01–07 与历史任务书归入 research；08、12、14、16、18 归入 plans；09–11、13、15、17、19 归入 validation。
- 归档文档里的跨文件引用已改为新相对路径；旧文件名保留，便于从历史提交和搜索结果追溯。
- 归档中的历史机器路径、旧版本描述或旧验证结论不代表当前环境；请以根 README、docs/当前文档和具体 Release 为准。
- 不要把归档中的研究文本、截图、日志、Key 或本地路径复制到新的公开示例；安全/隐私问题请按根目录 SECURITY.md 报告。
