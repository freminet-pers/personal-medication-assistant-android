## 核心架构

1. MainActivity 提供今日、药物、资料、健康和更多入口；助手与设置位于“更多”。
2. LunaDatabase 负责 SQLite、迁移、加密字段、occurrence、用药事件、视觉资料草稿和备份。
3. DataCipher 使用 Android Keystore AES/GCM；AiClient 固定 deepseek-flash，同时提供文本回答、官方检索和视觉 JSON 草稿。
4. 视觉输入先私有保存并压缩；原始响应、结构化结果和用户确认状态持久化；没有用户确认不会成为正式药物或健康事实。
5. OccurrenceEngine、ReminderScheduler、SafetyEngine 保留本地优先和确定性安全边界。

## 重要边界

- 本交付不是医生、药师、急救服务或完整临床相互作用数据库。
- Debug APK 使用 debug 签名，不是生产发布包。
- 未配置真实运行时 Key 时不会发出外部医疗请求；真实设备和在线接口验证必须在有 Key、网络、余额和可用设备时进行。
