## 参考项目与采用的呈现原则

以下项目仅用于学习公开呈现、安全披露和证据边界，不是依赖、背书或文本来源：

- [LoopKit/Loop](https://github.com/LoopKit/Loop)：在高风险自动化场景明确标出 experimental / not approved for therapy；本项目沿用“Technical Preview + 不作医疗承诺”的显眼边界。
- [Open mHealth DSU reference implementation](https://github.com/openmhealth/omh-dsu-ri)：把数据点 schema、操作元数据和 provenance 写进公开说明，并明确 early-stage / proper testing 边界；本项目对应保留来源、Provider/模型元数据和不确定性。
- [LibreHealth EHR](https://github.com/LibreHealthIO/lh-ehr)：以健康记录为主线组织项目说明；本项目把用药记录、提醒和本地资料放在 AI 之前。
- [Immich security policy](https://github.com/immich-app/immich/security)：提供私下漏洞披露、范围和不应公开的信息边界的示例；本项目在 [SECURITY.md](../SECURITY.md) 采用相同类型的入口，未复制其内容。

这些参考不代表本项目达到同等临床、安全、隐私或运维成熟度。
