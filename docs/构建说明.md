# 个人用药助手：v0.4.0 构建与安装说明

## Android 工程

验证环境：Android Studio JDK 17、Android SDK platform 35、Build Tools 35.0.0、Gradle wrapper 8.7、Android Gradle Plugin 8.6.1。包名为 `com.lunamax.medassistant`；本轮为 versionCode 4 / versionName 0.4.0。不要提交 `local.properties`。

在工作区根目录执行：

    Set-Location 'G:\项目\药\android-app'
    $env:JAVA_HOME = 'C:\Program Files\Android\Android Studio\jbr'
    .\gradlew.bat :app:assembleDebug --no-daemon --console=plain

Debug APK 位于 `android-app/app/build/outputs/apk/debug/app-debug.apk`。

## Windows 中文路径测试 workaround

直接在中文路径运行 `testDebugUnitTest` 时，Gradle 的测试 worker 可能报告测试类找不到。源码和输出不需要搬动，使用临时 ASCII 映射盘：

    subst X: 'G:\项目\药'
    Set-Location X:\android-app
    $env:JAVA_HOME = 'C:\Program Files\Android\Android Studio\jbr'
    .\gradlew.bat :app:testDebugUnitTest --no-daemon --console=plain
    subst X: /D

本轮使用 `X:\android-app` 跑完整单元测试；中文路径问题是测试 worker 的路径编码限制，不是 Java/Android 编译失败。

## 安装与 UI 验收

    $sdk = 'C:\Users\32726\AppData\Local\Android\Sdk'
    $adb = Join-Path $sdk 'platform-tools\adb.exe'
    & $adb install -r 'G:\项目\药\android-app\app\build\outputs\apk\debug\app-debug.apk'
    & $adb shell am start -n com.lunamax.medassistant/.MainActivity

API 36.1 AVD 已检查安装、冷启动、五页导航、AI 服务页、明暗主题、约 412dp、360dp 和 1.3 倍系统字号。没有真实 Key 时不要点击真实在线连接；协议测试使用 MockWebServer。

## 测试命令

Android 单元测试：

    .\gradlew.bat :app:testDebugUnitTest --no-daemon --console=plain

Occurrence 合同测试也可直接运行：

    $temp = Join-Path $env:TEMP 'personal-medication-occurrence-contract'
    New-Item -ItemType Directory -Force -Path $temp | Out-Null
    $javac = 'C:\Program Files\Android\Android Studio\jbr\bin\javac.exe'
    $java = 'C:\Program Files\Android\Android Studio\jbr\bin\java.exe'
    & $javac -d $temp 'android-app/app/src/main/java/com/lunamax/medassistant/OccurrenceEngine.java' 'android-app/app/src/test/java/com/lunamax/medassistant/OccurrenceEngineContract.java'
    & $java -cp $temp com.lunamax.medassistant.OccurrenceEngineContract
