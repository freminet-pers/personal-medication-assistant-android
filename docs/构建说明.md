# 个人用药助手：v0.4.0 构建与安装说明

这是 Technical Preview 的源码构建说明。文档中的路径均使用占位符；请替换为你自己的仓库目录和 Android Studio JDK 路径，不要把机器本地路径、Key 或健康资料提交到仓库。

## Android 工程

验证环境：Android Studio JDK 17、Android SDK platform 35、Build Tools 35.0.0、Gradle wrapper 8.7、Android Gradle Plugin 8.6.1。包名为 com.lunamax.medassistant；当前公开基线为 versionCode 4 / versionName 0.4.0。不要提交 local.properties、build/ 或 APK。

在仓库根目录执行（PowerShell 示例）：

    Set-Location '<repo-root>\android-app'
    $env:JAVA_HOME = '<Android Studio JDK 17 path>'
    .\gradlew.bat :app:assembleDebug --no-daemon --console=plain

Debug APK 位于 android-app/app/build/outputs/apk/debug/app-debug.apk。

## Windows 中文路径测试 workaround

如果在包含非 ASCII 字符的路径运行 testDebugUnitTest 时，Gradle 测试 worker 报告测试类找不到，可临时映射一个 ASCII 盘符；不要复制或公开应用数据：

    subst X: '<repo-root>'
    Set-Location X:\android-app
    $env:JAVA_HOME = '<Android Studio JDK 17 path>'
    .\gradlew.bat :app:testDebugUnitTest --no-daemon --console=plain
    subst X: /D

这是测试 worker 的路径编码 workaround，不是把应用数据搬到仓库的方法。

## 安装与 UI 验收

    $sdk = '<Android SDK path>'
    $adb = Join-Path $sdk 'platform-tools\adb.exe'
    & $adb install -r '<repo-root>\android-app\app\build\outputs\apk\debug\app-debug.apk'
    & $adb shell am start -n com.lunamax.medassistant/.MainActivity

公开验收记录只覆盖 API 36.1 AVD 的安装、冷启动、页面导航、AI 服务页、明暗主题、约 412dp/360dp 和 1.3 倍系统字号。没有真实 Key 时不要点击真实在线连接；协议测试使用 MockWebServer。API 26/API 35、实体设备、相机真实输入、通知行为和真实 API 流量仍未验证。

## 测试命令

Android 单元测试：

    .\gradlew.bat :app:testDebugUnitTest --no-daemon --console=plain

Occurrence 合同测试也可直接运行：

    $temp = Join-Path $env:TEMP 'personal-medication-occurrence-contract'
    New-Item -ItemType Directory -Force -Path $temp | Out-Null
    $javac = '<Android Studio JDK 17 path>\bin\javac.exe'
    $java = '<Android Studio JDK 17 path>\bin\java.exe'
    & $javac -d $temp 'android-app/app/src/main/java/com/lunamax/medassistant/OccurrenceEngine.java' 'android-app/app/src/test/java/com/lunamax/medassistant/OccurrenceEngineContract.java'
    & $java -cp $temp com.lunamax.medassistant.OccurrenceEngineContract

## 运行时 Key

Key 只能从应用运行时输入或安全环境变量提供，不得写入脚本、文档、Git、日志、APK 或测试夹具。没有 Key 时仍可使用离线功能，图片/PDF 可以保存为等待识别。发布前还需配置 release 签名、认证、限流、出口控制、密钥轮换和适当的隐私/安全审查。
