# 第三方声明

## DeepSeek Harness 与原生搜索

- 项目：<https://github.com/deepseek-ai/deepseek-harness>
- 审计提交：`ddefc45fbc7f8e46dd73185e68295696d1297887`
- 许可证：仓库根目录 MIT；官方说明仍将相关组件标为 developer preview/experimental，未替代本项目自己的安全审查。
- 本项目只采用其 Web Search/Web Fetch 的接口和安全约束，不把网页结果直接当作医疗结论，也没有把 Harness 执行器引入 Android APK。
- v0.4.0 的 Android 搜索直接使用协议原生工具：内置 DeepSeek 使用 Anthropic Messages 兼容入口与 `web_search_20250305`；自定义搜索支持 OpenAI Responses 原生 `web_search` 或 Anthropic Messages 原生 `web_search_20250305`。

## Android / AndroidX / SDK

Android SDK、AndroidX、Material Components、Gradle 与 OkHttp MockWebServer 按各自官方许可使用。应用使用平台 Java View、SQLite、AlarmManager、通知 API 和 AndroidX FileProvider；用户数据不交给第三方服务，除非用户在应用内明确确认联网请求。

## Provider 边界

OpenAI Chat Completions、OpenAI Responses 和 Anthropic Messages 是独立的原生协议适配器，不宣称兼容任意私有网关或任意 JSON。用户配置的第三方 Provider 可能记录请求内容、保留日志或有自己的隐私条款；在保存自定义域名和确认发送前，应先阅读其服务条款与数据处理说明。
