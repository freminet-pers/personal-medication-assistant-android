## 这一版包含什么

- 本地用药、提醒、库存、资料草稿和健康背景记录。
- 可配置的 OpenAI Chat Completions、OpenAI Responses 和 Anthropic Messages Provider。
- 选定 Provider 统一处理文字与图片草稿；图片能力需要声明并通过匿名能力测试。
- 独立 Search Profile、结构化来源和用户确认门。
- 按 Provider/Search Profile 隔离的 Android Keystore Key，以及 SQLite v6→v7 迁移。

## 使用边界

核心价值是本地个人记录和提醒；AI 只能在用户确认后辅助整理或核对资料。模型、网页和工具结果是不可信输入，回答应保留来源和不确定性。识别结果是待确认草稿，不会自动写入正式药物或健康字段。

API Key 不在仓库、日志、截图、APK 资源、SQLite 备份或导出会话中。配置自定义 Provider 前，请阅读其数据留存和隐私政策。出现紧急症状时，请联系当地急救服务或专业医护人员。
