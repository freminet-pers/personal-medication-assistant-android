# 个人用药助手：v0.3.0 用户使用说明

## 五个页面

- “今日”：查看当天计划，支持已服用、跳过、稍后 15 分钟和撤销。
- “药物”：管理药物、实际批次、库存和提醒计划；没有实际批次时不会扣减库存。
- “资料”：拍照或导入图片/PDF。文件先保存到私有目录，发送视觉模型前显示页数与大小并要求确认。
- “健康”：记录和确认过敏史、既往史、不良反应等最小必要资料。
- “助手”：管理运行时 Key、文本问题、思考深度（快速/深入/最大）、官方 Web Search 和本地会话。

右上角设置提供通知权限、精确闹钟、重建提醒、加密备份、导入、版本信息和彻底删除本机数据。

## 药物、批次与计划

在“药物”页新增或编辑药物。每个药盒在“批次”中单独记录批号、数量、日期、位置和储存条件。计划支持每日、每周、间隔、临时和按需用药，并生成未来 30 天 occurrence；确定性安全检查覆盖重复成分、过敏关键词、同刻计划、库存和有效期，不替代临床相互作用数据库。

## 资料与视觉草稿

图片生成上传用 JPEG 副本，PDF 按页生成 JPEG；原文件、压缩文件、页码、SHA-256、模型、提示版本、原始响应、结构化结果和失败原因都保存在本机。视觉模型固定为 `deepseek-v4-flash-vision-exp`，只转录可见文字，不确定字段保持空值并列入待核对项。

没有 Key 或网络不可用时，可保存为“等待识别”；配置 Key 后从资料页重试。只有用户逐字段确认后，结果才会写入正式药物、批次或资料。

## Key、助手与会话

在“助手”页输入运行时 DeepSeek Key。保存动作只做本机 Keystore 加密/解密自测，不自动联网；“测试连接”是单独操作。Key 使用独立 alias 保存，Key 状态异常只清理旧 Key，不清理健康数据。会话和消息在本地 SQLite 表中保存，导出备份不包含 Key。

文本与搜索固定使用 `deepseek-v4-flash`。发送前会显示当前有效药物、过敏记录和“其他资料需明确选择”的摘要；官方 Web Search 会产生联网请求，网页和模型抽取结果按不可信数据处理。回答需结合来源、不确定性和官方说明书核对。

应用不能替代医生、药师、官方说明书或急救服务。出现呼吸困难、意识改变、胸痛、严重过敏等急症信号时，应优先联系当地急救服务。
