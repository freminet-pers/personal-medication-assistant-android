# 个人用药助手：v0.4.0 用户使用说明

## 五个页面

- “今日”：查看当天计划，支持已服用、跳过、稍后 15 分钟和撤销。
- “药物”：管理药物、实际批次、库存和提醒计划；没有实际批次时不会扣减库存。
- “资料”：拍照或导入图片/PDF。文件先保存到私有目录，发送给当前 AI 前显示页数与大小并要求确认。
- “健康”：记录和确认过敏史、既往史、不良反应等最小必要资料。
- “助手”：查看当前 Provider、输入问题、选择思考深度、使用已测试搜索并保存本地会话。

右上角设置提供通知权限、精确闹钟、重建提醒、加密备份、导入、版本信息和彻底删除本机数据。备份和导出不会包含 API Key。

## 配置 AI 服务

在“助手”页点击“管理 AI 服务”：

1. 内置 DeepSeek 预设显示为 DeepSeek V4.1 Flash，实际模型 ID 为 `deepseek-flash`，文字与图片共用当前模型。
2. 点击“添加 AI 服务”可创建自定义 Provider。填写显示名、协议、base URL、模型 ID 和 Key；支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages。
3. “保存配置”只保存本机配置与 Key，不代表连接成功；必须再点击“测试连接”。
4. Key 只显示未配置/已保存/已测试状态，不会回显。每个 Provider 使用独立 Keystore alias。
5. 图片能力要先打开声明开关，再保存并点击匿名小图测试；测试通过前不会发送用户图片。

base URL 填服务根地址，不要填完整 `/chat/completions`、`/responses` 或 `/messages` endpoint。外部服务只允许 HTTPS；HTTP 仅允许本机回环地址用于测试。

## 独立联网搜索

“AI 服务”页的“独立联网搜索”分为三类：

- DeepSeek 官方搜索：仅内置 DeepSeek 预设可用，复用已保存的内置 DeepSeek Key。
- OpenAI Responses 原生搜索：使用 `web_search`。
- Anthropic Messages 原生搜索：使用 `web_search_20250305`。

自定义聊天 Provider 不会因为协议支持就自动启用搜索。用户必须明确保存 Search Profile，可选择明确复用当前 Provider Key，也可单独输入 Search Key，然后点击“单独测试”。只有测试返回结构化 URL 后，助手页的搜索开关才会可用；联网会产生外发请求。

## 药物、批次与计划

在“药物”页新增或编辑药物。每个药盒在“批次”中单独记录批号、数量、日期、位置和储存条件。计划支持每日、每周、间隔、临时和按需用药，并生成未来 30 天 occurrence；确定性安全检查覆盖重复成分、过敏关键词、同刻计划、库存和有效期，不替代临床相互作用数据库。

## 资料与统一多模态草稿

图片生成上传用 JPEG 副本，PDF 按页生成 JPEG；原文件、压缩文件、页码、SHA-256、实际 Provider、模型、协议、提示版本、原始响应、结构化结果和失败原因都保存在本机。识别使用当前选择的同一个 Provider/模型，不再单独选择 vision 模型。只转录可见文字；不确定字段保持空值并列入待核对项。

没有 Key 或网络不可用时，可保存为“等待识别”；配置并测试 Provider 后从资料页重试。只有用户逐字段确认后，结果才会写入正式药物、批次或资料。

## 隐私与医疗边界

API Key 不进入 SQLite 备份、日志、截图、源码或会话导出。用户确认后才会把最小必要上下文发往当前 Provider 或独立搜索域名；网页、工具结果、用户问题和 AI 识别文本都是不可信数据。

AI 不是医生、药师、官方说明书或急救服务。出现呼吸困难、意识改变、胸痛、严重过敏等急症信号时，应优先联系当地急救服务。
