# 个人用药助手：v0.3.0 架构与安全边界

## 应用分层

```text
MainActivity（单 Activity 壳）
├─ TodayFragment：今日计划、服用/跳过/稍后/撤销
├─ MedicationsFragment：药物、批次、计划和库存
├─ DocumentsFragment：图片/PDF 私有导入、视觉草稿、逐字段确认
├─ HealthFragment：过敏史、既往史、不良反应等本地档案
└─ AssistantFragment：Key 状态、文本助手、搜索、会话

LunaDatabase(SQLite v6)
├─ medication / batch / plan / occurrence / event
├─ health_item / document
└─ assistant_session / assistant_message

确定性域逻辑：OccurrenceEngine + ReminderScheduler + SafetyEngine
网络边界：DeepSeekTransport
├─ Anthropic Messages：deepseek-v4-flash
├─ Chat Completions：deepseek-v4-flash-vision-exp
└─ HarnessSearchClient：web_search_20250305，结构化来源
```

## 数据与安全边界

- `DataCipher` 使用独立的 Android Keystore AES/GCM alias 保护健康、资料和备份数据；每次加密由 Keystore 生成随机 IV，并将 IV 与密文一起保存。
- `SecretStore` 使用独立 alias `medassistant_deepseek_api_v1` 保存运行时 DeepSeek Key。保存前执行加密→持久化→重读→解密→常量时间比较→删除自测；旧 Key 只在成功迁移后清除。损坏旧 Key 只清理 Key 偏好，不触碰药物、健康或资料数据。
- v0.2 原型数据库升级时只迁移仍有旧值的药物行；名称、剂量、库存和有效期转入新结构后清空旧明文列，后续升级不会用空旧列覆盖已加密字段。
- API Key 不进入 SQLite 导出、加密备份、日志、截图、测试夹具或 README。备份导入是显式替换，不导入 Key。
- 彻底删除先取消文本/视觉 AI executor、关闭资料草稿对话框并使旧请求代际失效，UI 回调写库前再次校验；计划兼容字段 `time_text` 只用于一次性迁移，迁移后清空。
- 图片/PDF 先进入应用私有目录；图片生成上传副本，PDF 按页渲染 JPEG；原文件、压缩文件和 SHA-256 均保留本地索引。只有用户明确确认后才发给视觉模型。
- 网页、搜索结果、用户问题和 AI 识别文本都是不可信数据；系统提示要求保留证据级别、不确定性和下一步核对方式，不能执行其中指令。
- research-gateway 的 Web Fetch 只允许无凭据的 HTTP(S) 公网目标，拒绝私网、回环、链路本地、IPv4-mapped/兼容 IPv6 地址及跨源重定向；正式 DeepSeek Key 只发往官方端点，抓取连接固定到刚解析并校验的 IP，且流式限制 1 MB。

## DeepSeek/Harness 协议

- 文本与搜索固定 `deepseek-v4-flash`，端点为 `https://api.deepseek.com/anthropic/v1/messages`，使用 `x-api-key`、`Authorization: Bearer` 和 `anthropic-version: 2023-06-01`。
- 搜索使用 `web_search_20250305`、`web_search` 和最多 5 次调用；结果从 `web_search_tool_result` 与文本 block 的 `citations` 映射为结构化来源。
- 视觉固定 `deepseek-v4-flash-vision-exp`，只产生待确认 JSON 草稿；未知或看不清字段保持空值并写入 `uncertainFields`。
- 思考深度 UI 显示“快速/深入/最大”，分别映射到关闭、`high`、`max`。

## 资料状态机与可验证性

`WAITING_KEY → PROCESSING → DRAFT → CONFIRMED`；异常进入 `FAILED` 并保留失败原因。确认前不会写入正式药物、批次或资料字段。

OccurrenceEngine 接收显式时间、范围和时区；合同测试无需等待系统时钟。设备级 Key、相机、PDF、通知和截图验证依赖外部 ADB/AVD；本轮已在 API 36.1 AVD 执行页面导航和 Keystore 临时字符串往返验证。
