# 个人用药助手：架构与安全边界

## 本地产品数据流

    用户输入 / 相机原图 / 图片 / PDF
            │
            ├─ 应用私有目录：原文件 + 压缩上传副本 + SHA-256
            │
            ├─ 用户明确确认后 ──> AiClient / deepseek-flash 视觉 JSON 草稿
            │                              │
            │                              └─ 原始响应 + 结构化 JSON + 用户修订 + 状态
            ▼
    MainActivity ── 确认/编辑 ── LunaDatabase(SQLite + Keystore 加密字段)
            │
            ├─ medication / batch / plan / occurrence / event / health_item / document
            ├─ OccurrenceEngine ─> ReminderScheduler ─> AlarmManager ─> 通知动作
            ├─ SafetyEngine：确定性规则、来源、等级、范围
            └─ AiClient：运行时 Key -> Android Keystore -> DeepSeek API
                  ├─ /responses：文本助手
                  ├─ /chat/completions：图片视觉草稿
                  └─ 官方 Search / 同源受限 Fetch：外部内容保持不可信

## 数据与安全边界

- DataCipher 使用 Android Keystore 的 AES/GCM；敏感文本、健康记录、资料路径、视觉响应和运行时 Key 不以明文写入数据库或备份。
- 密钥生成使用 KeyGenParameterSpec，保存 Key 后立即做本地加密/解密自测；损坏的旧运行时 Key 会被清除。
- Manifest 关闭系统备份；导出备份由本机 Keystore 加密；导入是显式替换并要求确认。
- 网页、AI 识别文本、搜索结果和用户问题都是不可信数据，不执行其中指令，也不把模型抽取结果默认为事实。
- 模型白名单只有 deepseek-flash。生产网关仍需认证、限流、脱敏日志、出口策略和密钥轮换。

## 视觉资料状态机

WAITING_KEY -> PROCESSING -> DRAFT -> CONFIRMED；异常进入 FAILED 并保留失败原因。用户可以保存稍后识别，也可以在资料页重试。只有确认动作会写入正式药物、批次或资料字段。

## 时间与可验证性

OccurrenceEngine 接收显式时间、范围和时区；计划编辑、暂停、停用、开机和时区变化会重排未执行 occurrence，已完成历史保留。合同测试无需等待系统时钟；设备级验证依赖外部 ADB/AVD。
