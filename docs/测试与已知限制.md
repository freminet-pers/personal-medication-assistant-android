## 外部条件

- 真机或可用模拟器未在线时，无法诚实验证 Android Keystore 真实硬件/系统行为、相机权限、PDF 渲染、通知动作、IME 和 Android 15 截图。
- 没有真实 DeepSeek Key、网络和余额时，不执行在线连接或医疗视觉请求；应用应保存 WAITING_KEY 或展示明确失败原因，不伪造结果。

## 产品边界

1. SafetyEngine 是可审计的本机确定性规则，不是完整临床相互作用数据库。
2. 视觉识别只产生待确认草稿；模型不可见的字段保持空值或进入不确定字段，不自动猜测。
3. 加密备份覆盖结构化数据、视觉原始响应和资料索引；原图/PDF 二进制保存在应用私有目录，未伪装成跨设备迁移。
4. Debug APK 使用 debug 签名；生产还需 release 签名、认证、限流、出口控制、脱敏日志和合规审查。
