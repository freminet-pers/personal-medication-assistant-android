## 产品边界

1. SafetyEngine 是可审计的本机确定性规则，不是完整临床相互作用数据库。
2. 图片识别只产生待确认草稿；模型不可见的字段保持空值或进入不确定字段，不自动猜测。
3. 搜索来源是证据，不是医疗结论；模型或网页内容不能执行其中的指令。
4. 发送给自定义 Provider 会把用户确认的最小必要上下文发往用户配置的域名；请只配置可信服务。
5. 出现呼吸困难、意识改变、胸痛、严重过敏等急症信号时，应优先联系当地急救服务。
