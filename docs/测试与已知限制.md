## 产品边界

1. `SafetyEngine` 是可审计的本机确定性规则，不是完整临床相互作用数据库。
2. 视觉识别只产生待确认草稿；模型不可见的字段保持空值或进入不确定字段，不自动猜测。
3. 加密备份覆盖结构化数据、视觉原始响应和资料索引；原图/PDF 二进制仍在应用私有目录。
4. Debug APK 使用 debug 签名；生产发布还需 release 签名、认证、限流、出口控制和合规审查。
